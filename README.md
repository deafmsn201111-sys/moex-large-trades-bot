# MOEX Large Trades Telegram Bot

Бот мониторит сделки на Мосбирже через официальный MOEX ISS API и присылает в Telegram сделки, сумма которых больше заданного порога.

## Возможности

- Официальный MOEX ISS API.
- Официальный Telegram Bot API.
- Настройка тикеров и порогов через `config.yaml` или переменные окружения.
- Отправка только новых сделок.
- Очередь отправки в Telegram, чтобы опрос MOEX не блокировался отправкой сообщений.
- Без Redis/Postgres/сторонних платных сервисов.

## Ограничения

- MOEX ISS не присылает push/webhook. Бот опрашивает API.
- Бесплатный ISS подходит для алертов, но не является гарантированным HFT-фидом.
- Если сделок очень много, между опросами теоретически могут быть пропущены некоторые сделки.
- Для всего рынка сразу нужно много запросов. Лучше держать короткий список ликвидных тикеров.
- Для гарантированного real-time по всему рынку нужен платный market data feed.

## 1. Создать Telegram-бота

1. Открой в Telegram `@BotFather`.
2. Создай бота командой `/newbot`.
3. Скопируй токен бота.

Это значение будет `BOT_TOKEN`.

---

## 2. Добавить бота в канал

1. Создай Telegram-канал.
2. Добавь бота администратором канала.
3. Дай право публиковать сообщения.

В качестве `TELEGRAM_CHAT_ID` можно использовать:

```text
@your_channel# moex-large-trades-bot
